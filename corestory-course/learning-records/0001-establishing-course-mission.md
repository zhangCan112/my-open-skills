# 学习记录 0001：确立课程使命与知识边界

确立了本工作区的教学使命：用户要用 CoreStory playbooks 解决真实工程问题（遗留现代化、功能实现、测试生成、bug 修复），并把方法论沉淀为 my-open-skills 仓库中的可复用 Agent 技能。学习语言为中文讲解、英文术语保留。

关键约束：所有知识必须来自一手来源 https://docs.corestory.ai/playbooks（已抓取 18 个页面，含 all sub-playbooks），不依赖二手教程；课程以"会话制"每课一 playbook 的方式推进。

Evidence: 用户在开场问答中明确选择"在自己的工作中应用 playbooks"+"将 playbooks 蒸馏为 Agent 技能"两个目标，并指定中文课程语言。

Implications: 后续课程应始终同时服务两个目标——每课既要给"立即上手的实操步骤"，也要突出官方文档里的 Agent 技能文件（SKILL.md / AGENTS.md 安装形态），后者是技能沉淀的直接模板。
