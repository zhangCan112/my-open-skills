# NOTES.md — 教学偏好与工作记录

## 用户偏好（已确认）

- **学习语言**：中文讲解；技术术语、命令、MCP 工具名、报告结构保持英文原文。
- **学习目的**（双目标）：
  1. 把 CoreStory playbooks 用到自己手上的真实工程工作。
  2. 把这个仓库（my-open-skills）沉淀成可复用的 Agent 技能集合——从 playbook 自带 SKILL.md 中学方法论。
- **社区**：不主动加入社区，倾向在真实工作中验证。（勿反复建议加入论坛。）

## 课程设计决策

- 以 https://docs.corestory.ai/playbooks 全部页面为唯一一手来源（已抓取 18 个页面）。
- 课程是"会话制"：每课聚焦一个 playbook / 一个阶段，可几分钟内完成，必须能立即应用到用户自己的代码库。
- 每课含一个即时反馈的 quiz（同字数选项），并且指向官方文档原文作为 primary source。
- 首页保留原始文档地址 https://docs.corestory.ai/playbooks 。

## 课程地图（lessons/）

1. **0001** CoreStory 平台与核心交互范式（MCP、8 工具、Expert/Navigator/Verifier 三角色、对话生命周期）
2. **0002** Playbook 全景图：四大类 + 六阶段现代化框架 + 何时用哪个
3. **0003** 阶段 1：Codebase Assessment（评估工作流、评分、报告）
4. **0004** 阶段 2：Business Rules Extraction（BR-XXX、验证矩阵、Confidence Protocol）
5. **0005** 阶段 3：Target Architecture（7 Rs、行为标签、ADR）
6. **0006** 阶段 4：Decomposition & Sequencing（TCE、work package、依赖图）
7. **0007** 阶段 5：Spec-Driven Development（delta spec、六相位、TDD）
8. **0008** 阶段 5 变体：Monolith to Microservices（数据库拆分、Saga、strangler）
9. **0009** 阶段 6：Behavioral Verification（四层验证、等价报告）
10. **0010** Feature Implementation（六相位实现工作流）
11. **0011** Agentic Bug Resolution（failing-test-first 根因调查）
12. **0012** Feature Gap Analysis（七类 gap、报告）
13. **0013** Spec-Driven Test Generation（行为测试 vs 代码镜像测试）
14. **0014** Behavioral + E2E Test Generation（覆盖与旅程级）
15. **0015** M&A Technical Due Diligence（四域尽调）
16. **0016** Using CoreStory with Jira（四工作流、双 MCP 编排）
17. **0017** Spec Kit Companion（与 GitHub Spec Kit 集成）
18. **0018** 从 Playbook 到 Agent 技能（技能文件安装表、SKILL.md 模板、mission #2 落地）

参考文档：`reference/glossary.html`（术语表）。
