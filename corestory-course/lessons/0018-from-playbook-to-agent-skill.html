Lesson 18 · 收尾（课程的第二个目标）

从 Playbook 到 Agent 技能

本课的承诺：把前 17 课的方法论沉淀成能装进你的 Agent 配置（SKILL.md / AGENTS.md / MCP 工具）的可复用技能。

课程两个目标回顾

  • 目标 1：把 playbook 应用到你的真实工程工作。
  • 目标 2：把方法论沉淀为可复用的 Agent 技能（SKILL.md / AGENTS.md）。— 本课完成。

什么是"技能文件"（Agent skills）

技能是给 Agent 的独立知识包：一个 SKILL.md 前端（何时该用、核心规则），加必要的参考文件。核心艺术在"定义触发信号"——① 任务匹配什么样的工作、② 怎么判定任务完成。装进 harness（Claude Code / Cursor / Gemini CLI / opencode 等）后，Agent 在正确的时机自动加载它。来源

CoreStory 的现成技能资产

docs.corestory.ai 每个 playbook 页都附带两种可安装技能包——这是捷径：
→ Extreme（严格遵循具体）与 Lite（轻量快速）技能。
→ 装进各 harness 的说明：Claude Code（放入 ~/.claude/skills/）、Cursor（~/.cursor/rules/）、CLI 调用、AGENTS.md 引用。

把"课程"沉淀成"技能"的练习（三步法）

  1. 浓缩——挑一课（如"阶段一 Codebase Assessment"），把它压缩成"触发条件 + 关键步骤 + 停止条件"，去掉解释只留指令。
  2. 装进 harness——放到你的 skills 目录，或写进 AGENTS.md，然后用你的 Agent 试跑一遍真实任务。
  3. 迭代——技能不该一成不变：失败案例 → 提炼规则（参看 Evolving Skill 思路）；成功就固化，失败就改触发条件。

总结：课程主线

六阶段现代化（0003–0009）+ AI 开发（0010–0012）+ 测试（0013–0014）+ 集成高级（0015–0017） 你现在拥有了用 CoreStory 的整个工作世界观：先理解（Expert）→ 再定位（Navigator）→ 再验证（Verifier），每一步都有人的门禁。把方法论落地为技能，是你把这门课转到"你自己的工程"的最后一步。
