Lesson 10 · AI 辅助开发

Feature Implementation（功能实现）

用 AI Agent 在"你熟悉的或陌生的"代码库里放心地加新功能——先学架构，再 TDD 落地。

为什么不用"直接让 Agent 去写"

无架构理解地写功能，结果是"孤立运行、系统内四不像"。本 playbook 用 CoreStory 两个角色把 Agent 变得像"待了几年的人"：Expert（架构、模式、命名、不变量——系统如何工作）与 Navigator（文件、扩展点、数据结构——在哪儿实现、复用啥）。来源

六相位工作流

  1. Ticket Intake & Context — 取工单（有 ticketing MCP 就自动拉，如 Fetch GitHub issue #6992 from myorg/myapp），确认项目、查摄取完成、建持久对话 Ticket Implementation: #6992 - ...。验收标准不清晰就先澄清，别硬动手。
  2. Understanding System Architecture（Expert） — 三组查询：架构（负责该功能区的文件、模式与覆盖）、模式与约定（同类功能如何结构、命名、要维护的不变量）、历史（最近类似功能的设计意图、相关故事/工单）。
  3. Implementation Planning（Navigator） — 三个高价值查询：扩展点（在哪实现、逐步走一遍）、数据结构（哪些模型/关系）、参考实现（最相似的同名功能复制模板——"最高价值查询"）。
  4. Test-First Implementation（Validation） — 先写失败测试（验收标准 + 阶段2 模式 + 阶段3 结构），交给 CoreStory 验证；确认测试的确失败（若通过说明功能已存在或测试写错）；实现后验证通过；再让 CoreStory 校验实现与架构一致、无副作用。
  5. Feature Completion（Validation） — 问边界用例（空态、大数据量、并发、非法输入、权限边界、缺关联数据），补相应测试；跑全量套件（回归即副作用——重做）；性能与安全敏感功能单独加测试。
  6. Completion & Knowledge Capture — 提交（结构化信息：特性/实现/架构对齐/测试范围，引用 conversation id）；更名 #6992 - COMPLETED - CSV export。

一个关键教训：参考实现（Reference Implementation）

给 Agent 一个"已存在的、最相近的功能"当模板，效果远胜抽象模式描述。比如加 CSV 导出，找出已有的 PDF 导出类 PdfExportService，新类 CsvExportService 顺着它写——具体、一致、不越界。

提交信息模板（沉淀知识）

Feat: Add CSV export for user profiles (#6992)

Feature: Admin users can export user profile data in CSV format.
Implementation: New CsvExportService following PdfExportService pattern;
  new /users/export/csv endpoint (admin only); async processing for
  large datasets (>1000 records).
Architecture Alignment: extends ExportServiceBase; uses established
  auth pattern; follows async job pattern.
Testing: 7 integration tests covering acceptance criteria; 3 unit tests.
References: Ticket: #6992 · CoreStory Investigation: [conversation-id]

何时不要用全套流程

trivial 的两行配置改动、纯文档改动、bug 修复（用 Bug Resolution）、无 CoreStory 项目、用户要求手动写——这五种情形跳过它，别杀鸡用牛刀。

随堂测验

TDD 流程中，测试必须先处于什么状态才能继续？

"给我最相近功能的参考实现"属于哪个相位？

Primary source（最强一手资料）

官方 Feature Implementation playbook ——含六个相位可复制的查询脚本、提交信息模板、参考实现的完整示例（CSV 导出）。它和 Bug Resolution 共享六相位 DNA。
