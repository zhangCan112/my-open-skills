迁移 Review 术语表

以课程为准，全课程统一使用这些译名与缩写

核心概念

术语中文含义
Behavioral Equivalence行为等价迁移后系统在与旧系统相同输入下产生相同行为（含输出、副作用、错误路径）。
Business Rules Inventory业务规则清单从旧代码提炼的、逐条可验证的行为契约表（ID + description + legacy location + 等级）。
Golden Master黄金标准用真实输入在旧系统捕获的输出集合，作为新系统必须对上的基准。
Characterization Test表征测试把"旧系统实际输出"当规格来写的测试（源自 Michael Feathers）。
Shadow Traffic / Dark Launch影子流量生产请求同时打新旧两套，比较响应不一致。
Record-Replay录制回放抓生产流量，在新系统按序重放并对比结果（适合批处理）。
Reconciliation数据对账迁移后对比新旧数据：行数、校验和、派生字段、外键完整性。
Invariant不变量系统在任何时候都必须成立的约束，常不被文档化、只隐含在代码里。
HITL Gate人工闸门下线遗留代码前，领域专家对等价报告的签发确认。

差异分类词（第 3 课）

术语含义
MISSING旧行为新代码完全没有。
PARTIAL有但缺了分支/case/边界。
DIFFERS都在但行为逻辑变化。

变种术语（英文中常见变体）

英文笔记
parity check / parity testing与 behavior equivalence 同义，强调"输入-输出逐条对上"。
behavior preservation行为保持，等价说法。
equivalence reportBehavioral Equivalence Report 的缩写称呼。
intentional deviation / known deviation有意的、被记录下来的行为差异（如修掉旧 bug）。
regression不该发生的差异，必须修复。
