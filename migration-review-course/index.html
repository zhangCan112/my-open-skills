代码迁移 Review：对比前后、抓遗漏、盯业务变化

6 节课，从心智模型到报告签发。每课 5–8 分钟。先读 任务书 再开始。

课程地图

#主题核心产出
01心智模型：行为等价 ≠ 语法等价从"看代码"切换到"列行为"
02业务规则清单（契约优先）把旧代码变成一份可验证的规则表
03差异三分类 MISSING / PARTIAL / DIFFERS审查结果可复核、可计数
04隐形行为与不变量抓住 diff 看不见、最易崩的默认值/排序/时序/错误格式
05四层验证梯队（静态→表征→影子→对账）从"听起来对"到"跑出来对"
06Behavioral Equivalence Report + 人类闸门把结论变成可签发的报告
