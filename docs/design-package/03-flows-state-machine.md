## 一、主比较流程(时序)

```
用户                    扩展                         VS Code
 │ 入口①活动栏(推荐)      │                             │
 │──────────────────────▶│ 打开容器,Welcome 视图         │
 │ 点「选择两个项目…」      │ showOpenDialog ×2(可收藏)    │
 │──────────────────────▶│ 嗅探两侧同名配置文件           │
 │                       │ QuickPick 多选文件(分组展示)  │
 │ Enter 确认 ───────────▶│ withProgress(可取消)          │
 │                       │ 解析 → 规则判定 → DiffResult   │
 │                       │ 渲染树 + badge + 状态栏        │
 │ 点叶子 ───────────────▶│──────── vscode.diff ────────▶│ 打开虚拟文档对比
 │ 行内 ≈ / ⊘ ───────────▶│ 写 rules.json → 重算 → 刷新    │
```

- 入口②Explorer 右键:`Select for Config Diff`(A)→ `Compare with Selected`(B),仅对文件夹与配置文件出现。
- 入口③命令面板:命令注册但 UI 文案永不引导(INV-10)。

## 二、视图状态机

```
            ┌───────────┐  选择项目对   ┌───────────┐  选文件+确认  ┌──────────┐
   Idle ───▶│  Picking  │─────────────▶│ Comparing │─────────────▶│  Ready   │
            └───────────┘              └─────┬─────┘              └────┬─────┘
                 ▲      取消/EOF             │ 取消                    │ 文件改动
                 │◀──────────────────────────┘                        ▼
                 │                                             ┌──────────┐
            Error ◀── 解析失败/IO错误(文件级降级,不停整个流程)────│  Stale   │──刷新──▶ Ready
                                                                └──────────┘
```

- **Ready 内子态**:树(文件分组/状态分组)、选中叶子(→diff 打开)、过滤维度(报告)。
- **Stale**:DiffResult.generatedAt < 任一侧文件 mtime → 顶部黄条 + 树降透明;重比较后清除。**过期不自动重算**(用户可能正在改文件)。
- **Error 分级**:文件级错误只影响该文件对(其余继续);全局错误(IO/权限)→ 通知 + 树显示错误节点。

## 三、边界情况决策表(新手照此执行,不用再问)

| # | 情况 | 行为 | 理由/不变量 |
| --- | --- | --- | --- |
| E1 | 一侧文件解析失败 | 该文件对标 ⚠ 节点(列错误行号);其余文件照常比较 | 部分可用优于全不可用 |
| E2 | 文件仅一侧存在(无配对规则) | 不比较;QuickPick 中归入"仅单侧"分组提示可配对 | 规则可见性 |
| E3 | 文件配对规则把两侧文件配对 | 视为一个文件对,组名显示 `a ⇄ b` | — |
| E4 | 键两侧类型不同(string/number…) | status=type;若命中 coerce 规则 → equ | 判定优先级 |
| E5 | 数组值 | 按索引逐项比;长度差记为末位 onlya/onlyb;数组 vs 标量 = type | 语义对齐 |
| E6 | 对象 vs 标量同名键 | type | — |
| E7 | 文件内重复键 | 解析期警告(文件级 ⚠ 备注),后值覆盖前值参与比较 | 诚实告知 |
| E8 | 超长值(>120 字符) | 树摘要截断 40;表格省略+title;diff 视图完整+软换行 | INV-5 |
| E9 | 总差异 >5000 | 报告虚拟滚动+顶部提示;树默认折叠状态分组 | INV-7 |
| E10 | 空文件/空对象 | 视为 0 键;对侧存在键 → 全部 onlya/onlyb | — |
| E11 | 大小写:Windows .env 键 | 默认区分大小写;设置项 `configDiff.env.caseInsensitive`(默认 false) | 不做魔法 |
| E12 | 比较后用户编辑了文件 | Stale 态(E12 流程见状态机);不自动重算 | 避免比较打断编辑 |
| E13 | 两条规则同时命中同一键 | 书写顺序首个生效;ignore 类 > 等价类;规则视图支持拖拽排序(二期) | 可预测 |
| E14 | 忽略+等价规则同时命中 | ign 优先 | INV-4 |
| E15 | 规则开关后某文件对无差异了 | 该文件对行显示「✓ 完全一致」;badge/计数同步 | INV-3 |
| E16 | rules.json 语法错误 | 规则视图顶部错误条 + 用**上一次有效规则**继续比较;通知给出「打开文件」 | 可用性优先 |
| E17 | BOM/编码异常 | 按检测编码解析;失败 → E1 | — |
| E18 | 值含密钥样内容(.password/secret/…) | 报告/树默认打码 `sk-****`(设置可关);diff 视图不打码(本地) | 安全默认 |
| E19 | 项目对路径不存在(历史记录) | 历史项置灰 + 「重新选择…」 | — |
| E20 | 比较期间再触发比较 | 取消前一次,重新开始(带通知) | 单飞行任务 |

## 五、联动规范(双向)

- 树叶子 → 打开 diff:该叶子置 selected;diff 关闭不清除选中。
- 报告行 `⊙` → showScreen(树) + reveal 叶子(展开祖先)+ flash 1.6s。
- 报告 `≈/⊘` → 写规则重算后,受影响键行短暂高亮 + 通知「已生效(撤销)」。
- `⇄ 对调两侧` → DiffResult 整体重算(onlya↔onlyb 互换),侧栏描述与表头标签同步换名。
