# 05 · 验收清单(Acceptance Checklist)

> 逐条可测。`P0` = 阻断发布;`P1` = 二期可缓。测法写在括号里。

## A. 主题与颜色(INV-1/2)
- [ ] P0 切换 Dark+ / Light+ / High Contrast(内置主题),所有界面无硬编码色残留(肉眼 + `grep -rn "#[0-9a-fA-F]\{3,6\}" src/` 仅允许出现在 tokens 定义处)
- [ ] P0 六种状态徽标均为「颜色+图标+文字」三件套(灰度截图检查)
- [ ] P1 用户自定义主题(非内置)下无破相(随机装 3 个热门主题)

## B. 结果一致性(INV-3)
- [ ] P0 树计数 = 报告过滤芯片计数 = 状态栏数 = badge 数(构造 3 文件 87 键夹具,人工对账)
- [ ] P0 开关任一规则后,四处计数同步更新且与规则语义一致
- [ ] P0 修改规则后重新比较,无残留旧状态(过期条消失)

## C. 规则(INV-4)
- [ ] P0 规则命中的键在树/报告中可见 ≈ 或 ⊘ 标注,tooltip 含规则描述
- [ ] P0 开关规则 ≤100ms 生效(500 键夹具计时)
- [ ] P0 报告行内 ⊘ / ≈ 写入 rules.json,且可 Esc 撤销(10s 内)
- [ ] P0 rules.json 语法错误时降级用上次有效规则并出通知(E16)
- [ ] P1 违反 Schema 的规则不出现在规则视图,Webview 编辑器标红并给原因

## D. 树与联动(INV-5/6)
- [ ] P0 树层级 = 文件→状态→键原始嵌套(对照源文件抽查 10 键)
- [ ] P0 点叶子打开 vscode.diff,树中该叶 selected;diff 关闭后选中保留
- [ ] P0 ◫ 分组切换后计数一致;默认记忆用户上次选择
- [ ] P0 ⇄ 对调后 onlya/onlyb 互换、表头名称互换
- [ ] P1 报告 ⊙ 定位:树自动展开祖先 + flash

## E. 键级 Diff(C4)
- [ ] P0 虚拟文档首两行注释符合 T054–T058;语言 id 正确(yaml/env 有语法高亮)

- [ ] P0 F7 无障碍查看器可用(原生)
